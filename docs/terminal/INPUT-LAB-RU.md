# Терминал NekoFlash · тестовая ветка

`test/terminal-input-lab` началась с REV49 (`d186f50`), затем объединена с актуальным `main` (REV53, `b82af9f`) без перезаписи обновлённых ADB/USB/диагностических файлов. Это изолированный черновик PR #56, не релиз. Строка ввода следует за выводом. При заполнении окна прокручивается история, редактор остаётся доступным. В коротком окне служебные клавиши открываются кнопкой «Клавиши». Если клавиатура оставляет место только для редактора, терминал временно перекрывает верхнюю USB-панель. Если даже после этого нет места хотя бы для одной строки ответа, **после отправки HOST-команды** клавиатура скрывается: вывод становится читаемым, а новое редактирование доступно по нажатию на строку ввода. Простое вращение, набор текста и поток интерактивного ADB shell клавиатуру сами по себе не закрывают. Цвета и оформление берутся из темы приложения.

В этой ветке CI собирает **NekoFlash Terminal Lab** с идентификатором `ru.forum.adbfastboottool.dev.terminal`. APK ставится рядом с обычной DEV-сборкой. Параметр локальной сборки — `./gradlew -PterminalLab=true :app:assembleDebug`. У каждой установки свои настройки. Выбранная общая папка в «Загрузках» остаётся доступной обоим приложениям.

| Действие | HOST | Открытый `adb shell` |
| --- | --- | --- |
| Ввод и Enter | Редактирование строки, отправка одной команды | Ввод сразу передаётся устройству, Enter отправляет перевод строки |
| ↑ и ↓ | История команд и возврат к черновику | Стрелки удалённого терминала |
| ← и →, Home и End | Перемещение курсора | Управляющие последовательности |
| Tab | Дополнение имени программы или известной команды | Символ табуляции |
| Ctrl+C | Прерывание операции терминала или очистка черновика. Сочетание на физической клавиатуре копирует выделенный текст | Байт прерывания `0x03` |
| Esc, PgUp и PgDn | Скрытие клавиатуры, прокрутка вывода | Escape и перелистывание страницы |

## Проверка на телефоне

1. Без USB ввести `ad`, нажать Tab, дописать `de`, ещё раз нажать Tab и отправить. В истории должна появиться одна строка `> adb devices` с ответом под ней.
2. Ввести черновик с кириллицей и эмодзи, нажать ↑, повернуть телефон и нажать ↓. Черновик должен вернуться целиком. С открытой клавиатурой отправить `fastboot пример` в обеих ориентациях. Ошибка должна появиться в области вывода, заголовок и закрытие остаются доступными при смене ориентации.
3. При подключённом по OTG тестовом устройстве открыть `adb shell`, ввести `echo Байт`, затем `sleep 30`, нажать Ctrl+C и ввести `echo ok`. Завершить сеанс командой `exit` и проверить возврат к HOST.

Пример взаимодействия взят из [TerminalView](https://github.com/termux/termux-app/blob/master/terminal-view/src/main/java/com/termux/view/TerminalView.java) и [TerminalExtraKeys](https://github.com/termux/termux-app/blob/master/termux-shared/src/main/java/com/termux/shared/termux/terminal/io/TerminalExtraKeys.java). NekoFlash использует собственные Android-редактор, обработчик HOST и существующий транспорт ADB.

## Регрессионные ограничения

- CI-эмуляторы Android API 26 и 34 проверяют отображение **полной строки ответа** при горизонтальной IME, а не только наличие сообщения в сохранённой истории.
- При ответе HOST-команды список должен последовательно доводить последний результат в видимую часть после изменения размеров окна. При ручной прокрутке или выделенном тексте принудительное следование отключается.
- Если системная клавиатура оставляет меньше безопасной области для вывода, после отправки HOST-команды она скрывается. Никаких изменений управления вводом внутри интерактивного ADB PTY.
- Структурный тест `check_rev7.py` допускает только точный Git blob основного `DeviceViewModel` плюс единственный проверенный метод прерывания терминальной операции. Все изменения REV51–53 остаются защищёнными от неучтённых правок.
