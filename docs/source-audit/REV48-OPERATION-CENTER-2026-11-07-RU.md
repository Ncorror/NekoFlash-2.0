# REV48 · операционный центр и временное скрытие инструментов

7 ноября 2026. Рабочая ветка `fix/rev46-simple-tests-logs`, [PR #45](https://github.com/Ncorror/NekoFlash-2.0/pull/45).

Автор отдельно поручил улучшить операционный центр, проверить ошибки и временно убрать вкладку «Инструменты» в прошивке. Это заменяет прежнее решение отложить дизайн.

## Найдено и исправлено

| Проблема | Изменение |
| --- | --- |
| Карточка без прокрутки; длинный текст и очередь обрезаются | Отдельный layout, закреплённый заголовок со сворачиванием и NestedScrollView. Заголовок задачи, подробности и пять соседних шагов доступны целиком. Полный журнал по-прежнему в консоли. |
| Завершённые `100%` рядом с `VERIFY_PENDING` или ошибкой выглядят как успех | Проценты и полоса показываются только во время выполнения. После завершения отображается исходный verdict и пояснение; pending не становится успехом. |
| Центр не открывается для активной операции без объекта прогресса | Открытие допускается по факту активной операции; используется неопределённый индикатор. |
| При пересоздании Activity открытое окно исчезает, старое окно явно не освобождается | Окно и позиция прокрутки восстанавливаются только в той же исполнительной сессии; onDestroy закрывает старый диалог. Сворачивание не отменяет операцию. |
| Поворот заново запускает 9/20-секундный срок видимости результата | В Bundle сохраняется deadline по монотонным часам вместе с сигнатурой результата. Новая операция сбрасывает срок; другая сессия его не наследует. |
| Небольшие кнопки остановки/закрытия; длинные подписи | Кнопки не меньше 48 dp, нулевые отступы у значков; краткий статус и отдельное пояснение. Цветом выделяется состояние, а не вся рамка окна. |
| Старый выбор Tools может восстановить скрытую страницу | В переключении участвуют только Quick/Mass, индекс 2 заменяется на Quick. Layout инструментов и существующие обработчики сохранены для возвращения вкладки. |

Кнопка отмены закреплена под прокручиваемыми подробностями и доступна при длинном тексте. Информационная строка запуска приложения и обычная запись `UNLOCKED` не выводятся в карточке как диагностика ошибки.

Кнопки «Свернуть», «Открыть консоль», «Отчёты» и «Отменить операцию» имеют разные действия. Консоль и отчёты открываются по нажатию; открытое модальное окно перед этим закрывается. Запрос отмены блокирует повторную кнопку и не объявляет успешную остановку до ответа исполнительного слоя. Отмена не обещает откат уже записанных данных.

ADB/Fastboot, DeviceViewModel, сервис владения операцией и алгоритмы записи не изменены. Исходные логи и checkpoint не очищаются. Guard Home обновлён для извлечения только карточки центра; для Fastboot нормализуется только `visibility="gone"` кнопки Tools, остальные защищённые байты остаются прежними.

## Проверка

Четыре новых installed-app сценария проверяют: активность без процентов и независимое сворачивание; все пять исходов при прогрессе 100%; длинные подробности/шрифт 1.3/landscape/восстановление окна и запрос отмены; старый индекс Tools и работа Mass после пересоздания. В первом прогоне на API 26 после поворота тест не добрался до отмены с крупным шрифтом. В текущем варианте тест ждёт измеренной области, листает её настоящими касаниями до «Отчётов» и проверяет видимость отмены до и после восстановления. Тест REV47 проверяет, что поворот через 12 секунд не запускает заново 20-секундное автоскрытие.

Матрица API 26/34 запускает 27 сценариев и сохраняет реальные скриншоты состояний центра. Они используют UI-фикстуры, не выполняют USB-запись и не доказывают результат физической прошивки. Build, JVM и lint выполняются для того же коммита через Actions. Итоговый PASS определяется запуском текущего SHA в PR; этот документ не объявляет ещё не выполненные проверки успешными.

На телефоне проверить чтение длинной ошибки, сворачивание/повторное открытие во время работы, поворот, кнопку отмены и отсутствие старого табло после нового запуска. Новый TestBook сохраняет прежнюю схему импорта отметок, а сценарий скрытых инструментов помечается SKIP. APK и точные SHA/runId подставляются при упаковке CI.
