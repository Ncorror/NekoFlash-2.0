# REV39 — выделение и копирование строк терминала

Дата: 31.10.2026. База ветки: REV38 draft `90b19cefb1c03cd0b29052a104f2861100770980`.

## Проблема

`item_console_line.xml` отображал вывод только как обычный `TextView`,
без `textIsSelectable`. Пользователь не мог выделить и скопировать
интересующий фрагмент лога встроенным меню Android.

## Изменение

Добавлено `android:textIsSelectable="true"` в XML **строки** консоли,
не в поле ввода. Используется стандартная системная механика
выделения и Copy; не требуется доступ к буферу обмена, новая
кнопка, особое разрешение или внешняя библиотека.

`ConsoleLogAdapter`, хранение журнала, рендер 3000 видимых строк,
поведение scroll, команды, диагностические файлы и USB не менялись.
Реальные сырьевые логи остаются полными и отдельно доступны через
диагностический экспорт.

## Тест и оставшиеся проверки

Существующий Android-тест `closedTerminalDefersOutputAndReopensWithNewestTranscript`
проверяет наличие видимого `TextView`, `isTextSelectable`, наличие текста,
а также неизменность последней строки стенограммы. Число
инструментальных тестов не увеличено относительно REV38.

Требуется аппаратный тест долгого нажатия, контекстной панели Copy,
прокрутки при выделении и поведения при приходе новых строк.
Копирование через системный интерфейс выполняется только по действию
пользователя; никакой автоматической передачи текста/секретов нет.
`main` и защита релиза не затрагиваются.
