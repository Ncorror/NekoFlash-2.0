# NekoFlash 2.0 — согласованные решения

Статус: **дизайн согласован**. Реализация развивалась в REV5–REV25: пять вкладок, единая USB-панель, полноэкранный терминал, Sideload REV3 и Unlock REV4. Текущий результат и границы проверки интерфейса — в [отчёте REV25](../source-audit/REV25-UI-2026-10-29-RU.md). Утверждённые макеты не заменяют проверку установленного приложения.

- **REV2:** `NekoFlash-2.0-MASTER-DECISIONS-2026-10-09-RU-REV2.md`, реестр CSV и аудиты. Пять вкладок, общий дизайн, USB-панель, терминал.
- **REV3 (утверждено):** `NekoFlash-2.0-SIDELOAD-REV3-APPROVED-2026-10-10.md` — третья вкладка только Sideload, никаких дополнительных ADB-функций.
- **REV4 (утверждено):** `NekoFlash-2.0-UNLOCK-REV4-APPROVED-2026-10-10.md` — Mi Unlock, два визуальных состояния, подтверждение результата после reconnect.

Приоритет более поздних решений: REV4 / REV3 имеют приоритет над конфликтующими ранними REV2. Оригинальная ветка/проект NekoFlash Pro не используется.

Макеты HTML и PNG сохранены только для согласования внешнего вида. Они не являются исполняемым Android-экраном.
