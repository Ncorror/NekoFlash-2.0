# NekoFlash 2.0 — historical approved design archive

The files in this directory are **historical visual/decision references from REV2–REV4 (October 2026)**.

They are retained only because they document decisions and mockups that influenced the application. They are **not** the current Android implementation, release checklist, hardware test plan or source of truth for feature state.

Current precedence:
1. current `main` source and tests;
2. [current project status](../STATUS.md);
3. current hardware/release/security documentation;
4. this archive only for historical design context.

Old screenshots/HTML mockups may intentionally differ from the shipped UI. Do not turn an old REV statement into a new implementation task unless a current issue explicitly asks for it.
