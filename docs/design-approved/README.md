## Approved Design Decisions

**Historical design index (REV2–REV4).** The previous REV44 statement below is obsolete: development has advanced to merged DEV [baseline 6a8accd8](../DEVELOPMENT_STATUS.md) and real H1/H2/H3 physical testing is documented in the [evidence ledger](../testing/PHYSICAL-TEST-EVIDENCE-LEDGER-2026-11-08-EN.md). This index records approved mockups and decisions, not the current Android screen layout or a new test plan. At historical REV5 only Sideload REV3 had been ported.

- **REV2:** `NekoFlash-2.0-MASTER-DECISIONS-2026-10-09-RU-REV2.md`, decision register CSV, and static audits. Five tabs, unified shell, USB status strip, and terminal.
- **REV3 (Approved):** `NekoFlash-2.0-SIDELOAD-REV3-APPROVED-2026-10-10.md` — third tab is dedicated Sideload only, without extra miscellaneous ADB functions.
- **REV4 (Approved):** `NekoFlash-2.0-UNLOCK-REV4-APPROVED-2026-10-10.md` — Mi Unlock workflow, two visual states, outcome verification after USB reconnect.

**Precedence:** Later decisions take precedence: REV4 / REV3 override any conflicting earlier REV2 mentions. The legacy/separate NekoFlash Pro branch/project is not used.

HTML and PNG design mockups are retained solely for visual reference and UI alignment. They do not represent executable Android application screens.

# NekoFlash 2.0 — согласованные решения

**Архив утверждённых дизайнов REV2–REV4.** Формулировка о «текущем REV44» устарела: рабочая DEV-база уже [6a8accd8](../DEVELOPMENT_STATUS.md), а реальные результаты H1/H2/H3 есть в [реестре](../testing/PHYSICAL-TEST-EVIDENCE-LEDGER-2026-11-08-RU.md). Это согласованные макеты, не гарантированно актуальный интерфейс APK и не новый план испытаний. **Исторический REV5:** тогда был перенесён только минимальный Sideload REV3.

- **REV2:** `NekoFlash-2.0-MASTER-DECISIONS-2026-10-09-RU-REV2.md`, реестр CSV и аудиты. Пять вкладок, общий дизайн, USB-панель, терминал.
- **REV3 (утверждено):** `NekoFlash-2.0-SIDELOAD-REV3-APPROVED-2026-10-10.md` — третья вкладка только Sideload, никаких дополнительных ADB-функций.
- **REV4 (утверждено):** `NekoFlash-2.0-UNLOCK-REV4-APPROVED-2026-10-10.md` — Mi Unlock, два визуальных состояния, подтверждение результата после reconnect.

Приоритет более поздних решений: REV4 / REV3 имеют приоритет над конфликтующими ранними REV2. Оригинальная ветка/проект NekoFlash Pro не используется.

Макеты HTML и PNG сохранены только для согласования внешнего вида. Они не являются исполняемым Android-экраном.
