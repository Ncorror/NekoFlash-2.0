First connection

  1. Install NekoFlash on a phone with Android 8.0+ and USB Host/OTG.
  2. Connect both phones using a suitable OTG cable or adapter. Grant NekoFlash USB access.
  3. Choose a mode: USB debugging for ADB, the Fastboot screen for Fastboot, or Recovery for Sideload.

Host root is not required. Operations on the target depend on its mode and bootloader state.

ADB, Fastboot & Sideload

ADB: terminal, APK installation & files

Enable USB debugging on the target and accept its RSA prompt. A large Pull can resume after reconnecting, with final SHA-256 verification.

Fastboot: flashing & formatting

Boot the target into Fastboot. Choose the exact partition and a matching image. Quick Flash, a Mass Flash queue and devices without A/B slots are supported.

Sideload: ZIP through Recovery

Start ADB Sideload in the target's Recovery. Choose the ZIP in NekoFlash, then explicitly start sending it. File selection alone never begins flashing.

Retesting Xiaomi Unlock

NekoFlash previously unlocked POCO X3 Pro, POCO F5 and POCO X7 Pro. After rewriting the code, we need to repeat the full process on the updated version.

Mi Account sign-in and Fastboot detection are verified. If you are already planning to unlock your Xiaomi, Redmi or POCO, reply in Telegram. Include both device models, Android/firmware versions, the outcome and the in-app diagnostic ZIP.

Unlocking may erase user data. Xiaomi determines account eligibility and waiting periods.

What is verified

Hardware evidence & the validation build
  • POCO X3 Pro/vayu: format userdata, Fastboot wipe and subsequent Android boot.
  • X3 Pro → X3 Pro: repeated 128 MiB Pull/Push transfers with matching SHA-256.
  • Recovery/Sideload, ADB/Fastboot transitions and terminal rotation/input within the published hardware evidence.
  • alpha12 validation: 409 JVM tests, 29 installed-app tests on each of API 26/34, independent ext4/F2FS checks and no Lint findings.

Hardware qualification is based on the alpha11 campaign. One device's result does not qualify every phone.

Reporting a problem

Include both device models, Android and NekoFlash versions, the action and the exact outcome. Use the app's built-in diagnostic export.

POCO F7 / onyx as host

Intermittent USB receive failures are possible on this host. Resumable Pull preserves progress after reconnecting; the underlying compatibility cause remains unconfirmed.
