How to flash Android without a PC using another phone

You can use one Android phone as the USB host for a second phone and select the right flashing workflow. NekoFlash 2.0 provides Fastboot, Recovery ADB Sideload and image-flashing tools over USB OTG—without a desktop computer.

What you need

  • Two Android devices: a host with Android 8.0+ and USB Host/OTG support, and a target you intend to flash.
  • A data-capable USB cable or OTG adapter; charging-only cables are unsuitable.
  • The correct firmware image or update ZIP for the exact target model and firmware.
  • The signed NekoFlash 2.0 APK downloaded from the official GitHub release.

Step 1. Decide what you are flashing

Recovery update ZIP: if your target's Recovery supports ADB Sideload and the package is compatible, see the ADB Sideload tutorial.

Partition image (.img): for an exact-matching boot, vendor_boot or other Fastboot-compatible image, use the Fastboot tutorial. The target bootloader must permit that particular operation.

Custom recovery: TWRP or OrangeFox installation varies by partition layout and device; follow the custom Recovery tutorial.

Step 2. Connect the target over USB OTG

Install and open NekoFlash on the host, then connect the target using a data cable. Allow Android USB access on the host. Confirm the selected device and its current mode: regular ADB, Fastboot, Fastbootd, Recovery or Sideload. These modes are not interchangeable.

Step 3. Verify device and files before writing

Use the app's diagnostic information to check device identity, partition names and slot configuration. Check that your firmware or ZIP was made for the exact device. Do not guess whether the target uses A/B slots, dynamic partitions or a dedicated Recovery partition.

Step 4. Start only the matching operation

For Fastboot, select the exact partition and compatible image. For Recovery Sideload, choose the ZIP first, then use NekoFlash's separate Start action. ZIP selection does not itself flash the device. Read the target device's actual response; completing a USB transfer alone does not prove installation succeeded.

Do I need root or an unlocked bootloader?

The Android host running NekoFlash does not need root. The target may need an unlocked bootloader for specific Fastboot writes, depending on manufacturer policy. An authorized ADB session does not itself grant Fastboot flashing permission. See the Xiaomi bootloader unlock status for account restrictions and hardware verification boundaries.

After the operation

Confirm the result in Recovery or Fastboot and check whether the target boots correctly. If USB disconnects or the operation gives an ambiguous outcome, preserve the diagnostic export and do not blindly repeat a destructive write. The help section explains how to report a device-specific issue.
