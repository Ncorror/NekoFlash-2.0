ADB without a PC: use one Android phone to control another

NekoFlash turns an Android phone or tablet into the USB host for another Android device. You can use ADB shell, install APKs, and transfer files without connecting either phone to a PC.

What you need

  • Two Android devices: one host running NekoFlash (Android 8.0+ with USB host/OTG) and one target.
  • A USB data cable and, where required, a USB OTG adapter.
  • USB debugging enabled on the target, with permission to authorize the host.
  • The official signed NekoFlash APK on the host device.

1. Enable USB debugging on the target

Open the target’s Android Developer options and enable USB debugging. The setting location varies by manufacturer. Do not confuse USB debugging with OEM unlocking: ordinary ADB access does not require an unlocked bootloader.

2. Connect the two phones

Connect the target to the NekoFlash phone using a data-capable cable. Grant NekoFlash the Android USB access permission on the host. On the target, approve the RSA fingerprint dialog for this host. If the dialog does not appear, confirm that the cable supports data and that the correct phone is acting as USB host.

3. Run ADB commands

Open NekoFlash’s ADB terminal once the connected device reports an authorized ADB session. Start with a harmless check such as adb devices or adb shell getprop ro.product.model, using the command form supported by the chosen app screen. You can then use the app’s built-in shell, APK installation, and Push/Pull file workflows.

4. Transfer files and install APKs

Use Push to send a file from the host to a selected target path, or Pull to retrieve one from the target. APK installation requires Android to accept the package; app install permissions and device policies still apply. NekoFlash provides full operation logs and diagnostic export for troubleshooting.

ADB, Fastboot and Recovery are different modes

ADB through Android requires USB debugging and host authorization. Fastboot runs in the bootloader, while ADB Sideload is a separate Recovery transfer mode. Switching modes changes which operations are available. See the Fastboot guide and ADB Sideload guide.

What if ADB does not connect?

Check the USB host role, data cable, target USB debugging state and RSA authorization. If NekoFlash sees the device but ADB remains unauthorized, resolve authorization on the target first. Collect a diagnostic ZIP if the connection still fails; USB host behavior can vary by hardware.
