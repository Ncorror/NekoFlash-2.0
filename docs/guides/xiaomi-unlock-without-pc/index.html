Xiaomi bootloader unlock without a PC: what NekoFlash can do

NekoFlash includes Mi Account sign-in and Xiaomi bootloader unlock workflows using another Android phone as the USB host. The rewritten NekoFlash 2.0 unlock procedure still needs a full physical-device retest: it is not advertised as a verified one-click unlock.

Important: Xiaomi authorization is still required

Removing the PC from the USB connection does not bypass Xiaomi account permissions, device binding, official waiting periods or model/region restrictions. An accepted login does not by itself mean the bootloader can be unlocked. NekoFlash does not promise an account-policy bypass.

What you need

  • A compatible Xiaomi, Redmi or POCO target device and an Android USB-host phone with NekoFlash.
  • A reliable data cable/USB OTG connection, plus access to the target’s Fastboot mode.
  • The Xiaomi account and device eligibility required by Xiaomi for the current model and firmware.
  • Awareness that an authorized bootloader unlock may erase user data.

1. Review eligibility and device state

Confirm the exact model, Android/MIUI/HyperOS version, account state and current bootloader status. Follow Xiaomi’s applicable official device-account binding process. Requirements may differ by firmware, region and account.

2. Prepare the Android-to-Android connection

Install the signed NekoFlash APK on the host phone, connect the target over USB OTG and open the Xiaomi workflow. Verify that the app identifies the correct target before proceeding. If the target needs Fastboot mode, enter it using the device’s supported procedure.

3. Sign in and inspect the response

NekoFlash has hardware evidence for Mi Account sign-in/session acquisition and Fastboot device detection. Carefully read any server waiting-period, eligibility or authentication messages; these are authoritative responses of the Xiaomi service and target device.

4. Unlock only when officially permitted

The app’s end-to-end bootloader unlock behavior has not yet been revalidated on a locked device after the rewrite. Do not interpret a successful sign-in or a generic command response as an independently verified unlocked bootloader. A complete test must confirm the bootloader state again after reconnecting the device.

Help us validate the new release

Earlier NekoFlash versions were reported by the maintainer to have unlocked POCO X3 Pro, POCO F5 and POCO X7 Pro. This is historical evidence, not a claim that the current alpha12 unlock flow is fully verified. If you already plan a legitimate unlock, share your models, firmware, exact response and diagnostic export with the tester group.
