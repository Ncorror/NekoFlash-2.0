ADB без ПК: управляем Android-телефоном с другого телефона

NekoFlash позволяет одному Android-телефону работать USB-хостом для второго. Можно отправлять ADB-команды, устанавливать APK и передавать файлы, не используя компьютер.

Что потребуется

  • Два Android-устройства: хост с NekoFlash (Android 8.0+ и USB Host/OTG) и целевой телефон.
  • Кабель с передачей данных и при необходимости OTG-переходник.
  • Включённая «Отладка по USB» на целевом телефоне.
  • Подписанный APK NekoFlash из официального GitHub Releases.

1. Включи отладку по USB

На целевом устройстве открой настройки разработчика и включи «Отладку по USB». Расположение пункта зависит от прошивки. Для обычного ADB не требуется разблокировать загрузчик — не путай эту настройку с «Заводской разблокировкой».

2. Соедини телефоны по OTG

Подключи целевое устройство к телефону с NekoFlash. На хосте разреши приложению доступ к USB. На целевом телефоне подтверди RSA-ключ хоста в появившемся окне. Если запроса нет, проверь кабель с передачей данных и роли USB.

3. Используй терминал ADB

После авторизации открой ADB-терминал NekoFlash. Для начала выполни безвредную проверку устройства: adb devices или adb shell getprop ro.product.model в формате команд, который ожидает выбранный экран приложения. Далее доступны Shell, установка APK, Push и Pull.

4. Установка APK и передача файлов

Push отправляет файл с хоста на целевое устройство, Pull забирает файл обратно. Установка APK зависит от разрешений Android и политики целевого устройства. NekoFlash сохраняет подробный журнал операций и позволяет экспортировать диагностику.

ADB — не то же самое, что Fastboot

Обычный ADB работает при включённой отладке USB и авторизации. Fastboot — режим загрузчика, а ADB Sideload — специальный режим Recovery для отправки ZIP. Для них есть отдельные инструкции: Fastboot без ПК и ADB Sideload без ПК.

Если телефон не определяется

Проверь роль USB-хоста, кабель, отладку и RSA-авторизацию на целевом устройстве. Если оно видно, но статус ADB неавторизованный, сначала подтверди доступ на целевом телефоне. При повторяемой ошибке пригодится диагностический ZIP.
