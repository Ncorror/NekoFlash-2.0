Как прошить Android без компьютера с другого телефона

Один Android-телефон может выступать USB-хостом для второго. NekoFlash 2.0 позволяет использовать Fastboot, Recovery ADB Sideload и прошивку образов по USB OTG без компьютера.

Что потребуется

  • Два телефона: Android-хост с NekoFlash (Android 8.0+ и USB Host/OTG) и целевое устройство.
  • USB-кабель с передачей данных или OTG-переходник.
  • Прошивка, образ IMG или ZIP, предназначенные точно для целевой модели и её прошивки.
  • Официальный подписанный APK NekoFlash 2.0 из GitHub Releases.

Шаг 1. Выбери правильный способ прошивки

ZIP через Recovery: если Recovery поддерживает ADB Sideload и архив совместим, открой инструкцию по ADB Sideload.

Образ раздела (.img): для совместимого boot, vendor_boot и других образов смотри инструкцию Fastboot без ПК. Загрузчик целевого устройства должен разрешать нужную запись.

Установка TWRP или OrangeFox: порядок зависит от разметки конкретного устройства. Есть отдельная инструкция по Recovery.

Шаг 2. Соедини телефоны через USB OTG

Открой NekoFlash на телефоне-хосте, подключи целевое устройство кабелем с передачей данных и разреши доступ к USB. Проверь, что выбрано нужное устройство и правильный режим — ADB, Fastboot, Fastbootd, Recovery или Sideload. Эти режимы отличаются.

Шаг 3. Проверь модель и файлы

Посмотри информацию об устройстве, разделах и слотах перед записью. Файл IMG или ZIP должен соответствовать модели и версии прошивки. Не предполагай наугад наличие A/B-слотов, динамических разделов или отдельного раздела Recovery.

Шаг 4. Выполняй только подходящую операцию

В Fastboot выбери точный раздел и совместимый образ. Для Recovery Sideload сначала выбери ZIP, затем отдельно нажми запуск передачи. Сам выбор архива не начинает прошивку. Успешная передача по USB ещё не доказывает, что Recovery установило пакет: проверь результат на устройстве.

Нужен ли root или разблокированный загрузчик?

Телефону-хосту с NekoFlash не нужен root. Для некоторых Fastboot-записей целевой загрузчик должен быть разблокирован — это зависит от производителя. ADB-авторизация сама по себе не даёт разрешения на прошивку через Fastboot. Для Xiaomi есть отдельная страница о разблокировке без ПК и состоянии проверки.

Что проверить после прошивки

Проверь результат на экране Recovery или Fastboot и корректную загрузку устройства. При обрыве USB или неопределённом результате сохрани диагностику и не повторяй разрушающую запись вслепую. В разделе помощи описано, какие сведения нужны для отчёта.
