# NekoFlash 2.0 — безопасная проверка REV6 на двух телефонах

**Статус:** инструкция для ручной проверки; автоматические тесты GitHub Actions не заменяют её.  
**Проверяемая ветка:** `feature/rev6-shell`. **Слияния в main ещё нет.**

## Сборка

1. Открой [сборки ветки REV6](https://github.com/Ncorror/NekoFlash-2.0/actions/workflows/build.yml) и выбери **последний успешный запуск** по `feature/rev6-shell` (старые артефакты до добавления `.dev` для проверки не подходят).
2. В нижнем блоке **Artifacts** скачай ZIP с названием `NekoFlash-…-debug`.
3. Распакуй архив через «Файлы» Android. Рядом с APK будет `checksums-sha256.txt`; проверь хэш: `sha256sum имя-файла.apk`, результат должен совпасть с файлом контрольных сумм.
4. Устанавливай только **Debug APK из последнего успешного запуска**. Его пакет — `ru.forum.adbfastboottool.dev`: он устанавливается *рядом с оригинальным NekoFlash*, а не поверх него. Оригинальный NekoFlash **не удалять**, не стирать его данные. Первоначальные запросы разрешений и онбординг у DEV отдельные.

## Устройства

- **Телефон-хост:** запускает NekoFlash 2.0 DEV и подключён к USB OTG.
- **Телефон-цель:** ранее выделенный для тестов Poco X3 Pro с **разблокированным загрузчиком**.
- Второй телефон с заблокированным загрузчиком в REV6 **не используем**.
- Нужен кабель передачи данных. При неверной USB-роли остановиться и исправить подключение, а не отправлять команды.

## Порядок проверки без записи в память устройства

1. **Без USB.** Запусти DEV-приложение. Проверь, что пять вкладок внизу, не перекрываются системной панелью, а USB-панель остаётся сверху. Открой каждую вкладку. **Sideload** содержит только утверждённые кнопки и выбор ZIP; **Unlock** открывается без запуска разблокировки.
2. **Терминал.** Кнопкой `>_` разверни на всю доступную область под USB-панелью. Проверь ввод символов и вставку длинной команды из буфера. Открой/закрой клавиатуру; убедись, что строка ввода не заезжает под IME. Back сначала закрывает клавиатуру, затем терминал. Повтори три раза. При свёрнутом терминале нет пустого нижнего блока.
3. **USB-панель.** Нажми на верхний статус и посмотри подробности; нажми «Обновить / поиск устройств». Проверь, что состояние и разрешение USB обновляются; при отсутствии устройства приложение не падает.
4. **ADB.** Подключи **тестовый** телефон в обычном Android. Разреши отладку по USB на телефоне-цели, если Android запросил. Проверь, что NekoFlash видит именно подключённый телефон и статус остаётся стабильным при переключении вкладок. Можно выполнить *только читающие* команды `adb devices` и `adb shell getprop ro.product.model` при доступном ADB; запускать прошивку/установку не нужно.
5. **Fastboot (не обязательно для базового REV6).** Переведи *разблокированный* тестовый телефон в Fastboot его аппаратной комбинацией клавиш, подключи к хосту и проверь только обнаружение и чтение статуса. Не использовать `flash`, `erase`, `format`, `unlock`, `set_active`, `boot` и любые команды изменения разделов.
6. **Навигация.** С устройством и без него проверь перенос статусной полосы операции и нижних вкладок на разных экранах, в портретной ориентации и с открытой клавиатурой. Проверку реального прерывания прошивки в REV6 не выполнять.

## Что прислать для аудита

- 3 скриншота: главная без USB, открытый терминал с клавиатурой, USB-панель с подключённым тестовым телефоном.
- Описание: Android на телефоне-хосте, тип соединения (USB-C–USB-C / OTG адаптер), обнаружение в ADB и Fastboot, ввод/вставка/Back.
- Диагностический ZIP только после просмотра/удаления персональных данных, серийных номеров и токенов.
- Если приложение падает — укажи конкретное действие, при котором произошёл сбой.

## Критерии перед merge

- GitHub: успешные REV5/REV6 guard, lintDebug, assembleDebug и Debug-артефакт.
- На устройстве: стабильное переключение пяти вкладок, нет наложения системной навигации, USB-панель работает, терминал принимает ввод/вставку, корректно реагирует на IME/Back.
- Неизменённые REV3 Sideload, REV4 дизайн Unlock и транспорт USB/ADB/Fastboot — отдельные охраняемые требования.
- **Пока ручная проверка не проведена, PR #1 остаётся Draft.**
