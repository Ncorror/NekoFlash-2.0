### Дополнительная сверка ссылок и полноты индекса (D30)

- Дерево `main` содержит **431 отслеживаемый файл**; 180 файлов имеют расширения из набора Markdown/HTML/XML/JSON/YAML/TXT, из которых **111** относятся к `docs/`, публичным корневым материалам и `.github/`. Это **инвентаризация**, а не утверждение о ручном чтении каждого файла.
- Во **всех 8 активных RU/EN HTML-страницах практических руководств** (`docs/guides/`, `docs/ru/guides/`) нашлись **37 ссылок** на старый GitHub URL `https://github.com/Ncorror/NekoFlash`, который сейчас через GitHub API отвечает 404. Ссылки на репозиторий, `releases/latest`, Privacy и Assets License заменены на действующий путь `https://github.com/Ncorror/NekoFlash-2.0` **без смены имен релизов и без подмены содержимого исторических справок**. Сам старый `Ncorror/NekoFlash` может быть приватным либо удалённым; публично доступного подтверждения ему не найдено.
- **Ограничение:** исторические canonical/GitHub Pages URL вида `https://ncorror.github.io/NekoFlash/` не перенаправлялись вслепую. Живой адрес публикации Pages не удалось достоверно проверить; до проверки GitHub Pages settings/публичного HTTP не заявлять, что канонический путь исправен или что миграция домена одобрена. Внешние Telegram/зеркала/пакетные ссылки не считаются автоматически проверенными только локальным link checker.
- Текущий CI `tests/check_docs.py` проверяет локальные ссылки, но он **не выполняет полноценное HTTP-тестирование всех внешних ссылок**. Если CI не обнаружил ошибок, это PASS проверяемых структурных и локальных контрактов, не доказательство универсальной доступности сети.

- **TestBook и сохранение данных:** `docs/insiders/testbook.html` с 43 карточками, офлайновыми RU/EN/ZIP/JSON, оригинальными логами оставлен без изменений; экспорт Chrome `content://` **всё ещё не подтверждён физически** ([#49](https://github.com/Ncorror/NekoFlash-2.0/issues/49)). Инструмент APK SAF экспортирует отдельно, не приравнивать.

Старые security review / утверждения о доступах к GitHub остаются датированными, **не считаются новой проверкой административных настроек**.

**Что не входит в выполненный аудит:** полная ручная проверка каждого байта всех 431 файлов репозитория; фактический выход на сайты за пределами GitHub, живые доступы к настройкам branch protection, тестирование новых устройств и исходные приватные ZIP с повторным вычислением байтов в этом же документальном коммите. CI-структурные и локальные link checks будут оценены на точном SHA этого документального PR. Эти ограничения не отменяют детальной сверки публичных документов и аппаратных сводок.

### D18 — первичные архивы первоначально пропущены при «полном» аудите

После замечания автора была выполнена локальная read-only проверка **10 ранее переданных ZIP** (девять диагностических и `NekoFlash_Hardware_QA_20261107.zip`): CRC всех архивов и размеры/SHA-256 каждого файла из доступного `EXPORT-MANIFEST.txt` (55/55, 103/103, 46/46, 31/31, 23/23, 65/65, 11/11). Результаты, точные сборки, количество операций, промежуточные FAIL и границы полноты внесены в [приложение к реестру](PHYSICAL-TEST-EVIDENCE-LEDGER-2026-11-08-RU.md). Прежний аудит не имел права объявлять аппаратные тесты «не пройденными» без просмотра этих материалов. **Исходные личные ZIP в GitHub не загружались и не изменялись.** Кроме исходной отметки о физическом PASS терминала 7 ноября, не утверждать, что конкретные три пользовательские отправки получили три отдельные подтверждённые точные SHA — публичный комментарий этого не доказывает.

## Оставшийся объём

Аудит публикационных вводных и фактических утверждений о проведённых тестах **не является машинной проверкой каждой ссылки/каждой строки всего репозитория**, не заменяет Android-код-аудит и не доказывает, что приватные ZIP повторно проверены здесь. Если обнаружится новый исходный архив, реестр обновляется по его проверенным данным и SHA, без переписывания прежних результатов.
