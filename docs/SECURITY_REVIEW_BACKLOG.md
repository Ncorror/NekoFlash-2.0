Сверка 30 октября 2026 по коду рабочей ветки после REV27 (`8806222d8590`) и стороннему пятистраничному **статическому** обзору REV26 от 30.10.2026. Формулировка обзора «нет High/Critical» **не равна** гарантии отсутствия уязвимостей; присвоенные ниже P0/P1/P2 — **приоритет выполнения**, а не оценка CVSS.

## Отдельный выпускной риск, подтверждён по workflow

**P1 до любого публичного release.** `.github/workflows/release.yml` запускается на любой тег `v*` с `contents: write` и проверяет совпадение тега с `versionName`, но не доказывает, что тег указывает на одобренный merge в `main`. Перед выпуском требуется явный проверяемый release-base policy и защита от подписи неутверждённого коммита. Также проверить пиннинг GitHub Actions по SHA и permissions.

## Критерии закрытия

Для каждого пункта: ссылка на отдельный PR/коммит, новые негативные и позитивные тесты, PASS CI на API 26/34, проверка реального устройства там, где тест-эмулятор недостаточен; сопроводительные изменения `PRIVACY` / предупреждений UI / release notes. Только после этого менять статус на «исправлено». Для опасных операций обязательны согласованные тестовые устройства, заранее сохранённые пользовательские данные и документированный rollback. Сырые серийники, аккаунт-токены и ключи не публиковать.
