## Что проверить на телефонах

1. На HOST без второго телефона проверить клавиатуру, поворот, выделение и закрытие терминала по [TERM-01](https://github.com/Ncorror/NekoFlash-2.0/issues/20).
2. На паре HOST → TARGET зафиксировать USB-роли, RSA и повторное подключение. Передать одноразовый файл по ADB и сравнить SHA-256 после возврата. Отдельно проверить 512 файлов и Stop при передаче пользовательских тестовых файлов.
3. Проверить на запасном TARGET чтение Fastboot getvar и экспорт журнала. Запись разделов и проверка ответа после DATA требуют отдельного согласованного сценария, резервной копии и пути восстановления.

Подтверждённого аппаратного протокола для контрольного APK REV45 в матрице пока нет. Для отчёта укажи обе модели, ОС, кабель, build ID, тест и фактический результат. Первичные логи передавай лично ответственному тестировщику. [Матрица](../HARDWARE_VALIDATION.md) · [Комплект](README.md).
