# NekoFlash 2.0 — post-release audit, 13 November 2026

## Scope

This audit covers the repository after publication of `v6.0.0-alpha11`: source, tests, CI/release workflows, scripts, active documentation, public Pages content, release assets, licensing and current GitHub state.

It is a repository/source audit plus previously collected physical evidence. It is **not** a mathematical proof of absence of security defects and it does not invent unperformed hardware tests.

## Verified starting state

- Signed release `v6.0.0-alpha11` exists and the published APK certificate matches the pinned permanent certificate.
- Public release assets are limited to APK, APK SHA-256 and the required filesystem corresponding-source archive.
- `main` CI #746 completed SUCCESS before the audit branch.
- Open Issues: 0.
- Open Pull Requests: 0.
- Long-lived branches before the audit: only `main`.
- GitHub repository rulesets API returned an empty list. Branch-protection details could not be read with the connected GitHub App permission.

## Findings corrected by this audit

### Application/share privacy
The shareable sanitizer handled structured serial fields but did not explicitly mask serial values in commands such as `fastboot -s SERIAL ...` / `adb -s SERIAL ...`. The audit adds explicit selector redaction and JVM regression tests. **Raw forensic logs remain unchanged by design.**

### Release provenance
The manual tag path accepted any tag whose commit was an ancestor of current `main`. The audit tightens this to the exact current `main` commit. The release-request path already required exact current main plus exact-SHA CI.

The release workflow also forced alpha/beta/rc to prerelease even though alpha11 was intentionally published as a normal/latest Release. The audit removes that mismatch and publishes future approved releases as normal/latest unless policy changes again.

### Tooling
- Old `Insiders` naming is removed from the generic APK-only tester kit.
- Obsolete `termux-fetch-rev9-dev.sh`, which referenced a deleted historical branch, is removed.
- Termux CI/publish defaults are corrected to `Ncorror/NekoFlash-2.0`.

### Documentation
Multiple files still described PR #78, open #64/#72, unsigned-release gates, old REV campaigns or a Sideload picker that immediately flashed. Those statements were correct only for older snapshots and unsafe as current instructions.

The active documentation is consolidated into a small set of current source-of-truth files. Superseded REV/refactor/source-audit snapshots are removed from the active tree and remain available in Git history.

### Public site
Canonical/OG/sitemap/404 links are corrected from the old `NekoFlash` repository path to `NekoFlash-2.0`. The Sideload guide is updated to the shipped explicit Choose → Start behavior.

## Findings intentionally not “fixed”

- Raw diagnostics in shared workspace: intentional professional policy; changing storage silently would break existing workflows and forensic access.
- Persistent Xiaomi WebView session until explicit Logout: current intentional behavior, now documented accurately.
- POCO F7/onyx intermittent USB IN behavior: hardware/host compatibility case; resumable Pull mitigates long transfers without pretending the electrical/root cause is known.
- Bundled GPL/component-licensed filesystem tools: corresponding source remains a required Release asset.
- GitHub rulesets: this is an administrative Settings action, not something this source audit can truthfully claim to have enabled. See [REPOSITORY_SECURITY.md](REPOSITORY_SECURITY.md).
